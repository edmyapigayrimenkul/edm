## Yeniden üretme

Site dizininde, mevcut Cloudflare ortamıyla salt okunur güncel sorgu:

```sh
npm run --silent quality:report -- --remote --markdown
```

Kaydedilmiş Wrangler JSON sonucuyla ağsız çalıştırma:

```sh
npm run --silent quality:report -- /tmp/edm-canli-kalite-guncel.json --markdown
```

Sorgu: `site/scripts/kalite-snapshot.sql`. Kurallar: `site/src/lib/ilan-kalite.ts`. Canlı panelde İlanlar ekranı aynı kuralları güncel portföye uygular.
